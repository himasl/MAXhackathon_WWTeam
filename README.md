# Маршрут

Чат-бот MAX с мини-приложением для студентов, переехавших на учёбу в другой регион. По ответам на 7–8 вопросов он строит персональный план дел после переезда (регистрация, полис и поликлиника, студенческий проезд, меры поддержки) и ведёт по нему через напоминания в чате. У каждого шага есть причина, документы, место, рекомендуемый срок и официальный источник.

Трек «Забота о людях». «Маршрут» — не государственный сервис: он не принимает юридически значимых решений и не гарантирует право на льготу. Шаги отбирает детерминированный движок правил, LLM не используется.

| | |
|---|---|
| Бот | [@t818_hakaton_max_bot](https://max.ru/t818_hakaton_max_bot) → `/start` → «Открыть маршрут» |
| Mini App и API | https://marshrut-tf5o.onrender.com · Swagger: `/docs` |
| Контракт API | [`openapi.yaml`](openapi.yaml) · [`DATA-API.yaml`](DATA-API.yaml) |

## Основной сценарий

```text
/start → «Открыть маршрут» → анкета → маршрут → шаг (причина, документы, место, срок, источник)
→ «Отметить выполненным» → следующий шаг → … → «Маршрут завершён»
```

Параллельно бот присылает: «маршрут готов», следующий шаг, напоминание о сроке, итоги недели и поздравление. Шаг можно закрыть прямо из чата.

## Возможности

- **Персональный план.** Шаги отбираются по анкете. В регион подставляются официальные МФЦ, фонд ОМС и студенческий проезд: хотя бы один такой источник есть у всех 89 регионов.
- **В приложении:**
  - «План по дням»;
  - «🎒 Что взять с собой» — документы по местам, список можно прислать в чат;
  - «Найти рядом» — Яндекс Карты у текущего местоположения;
  - срок в календарь (.ics);
  - «Мне это не нужно» — пропустить шаг;
  - работа без интернета: показывается сохранённая копия маршрута.
- **Помощь и близкие:**
  - раздел «Если что-то пошло не так» — паспорт, полис, болезнь, мошенники, телефоны;
  - ссылка для родителей только с прогрессом;
  - приглашение одногруппника;
  - карточка «Освоился за N дней».
- **Вопрос по шагу.** «Задать вопрос по шагу» в приложении и вопрос текстом боту. Отвечает RAG-сервис (`RAG_URL`), а пока он не подключён — встроенный поиск по шагам маршрута студента. Ответ всегда с официальными источниками и кнопкой «Открыть шаг». Подключение RAG — [`docs/rag.md`](docs/rag.md).
- **Иностранные студенты.** Отдельный сценарий: миграционный учёт, дактилоскопия, страховка. Интерфейс и бот на английском, язык определяется по телефону.
- **Для команды.** Панель команды в мини-приложении (вкладка «Команда» или `/admin` в боте, только для `SUPPORT_MAX_USER_IDS`): бизнес-статистика (активность по дням, воронка, регионы, вузы, где застревают), правка ссылок по регионам с отметкой «проверено сегодня» — правка не перезаписывается при деплое, разбор отзывов «Сообщить о неточности». Отзывы и оповещения об ошибках также приходят раз в день сводкой в MAX, `/stats` в боте — краткие метрики.

### Возможности MAX сверх минимума

- **Действия прямо в чате.** Callback-кнопки под сообщениями бота: «✅ Выполнено», «⏰ Напомнить завтра», «🚶 Уже в процессе». Шаг закрывается без открытия приложения, сообщение заменяется подтверждением (`POST /answers`).
- **Deep link из сообщения в конкретный шаг.** `open_app` с `payload=step_<id>` или подписанная ссылка `?t=…&start=step_<id>`.
- **Приглашения по коду вуза.** Ссылка `?start=<код вуза>`: бот здоровается от имени вуза, анкета заполняется сама.
- **Проактивные сообщения бота:** напоминания о сроках (с учётом тихих часов 22:00–9:00 по местному времени) и итоги недели.
- **Отправка через MAX.** «Поделиться» (`shareMaxContent`) — для приглашения, ссылки для родителей и достижения. Отправка списка «Что взять с собой» в чат.
- **MAX Bridge.** Вход по `initData` с проверкой подписи, системная кнопка «Назад», виброотклик, открытие ссылок, определение платформы.

## Состав и архитектура

Один сервис FastAPI отдаёт API, собранное мини-приложение и принимает события бота. PostgreSQL хранит профили, маршруты и отзывы. Сценарии и справочники хранятся как данные в `data/` и загружаются при старте.

```text
MAX (бот) ──webhook / polling──┐
MAX (Mini App, React) ──HTTPS──┤
                               ▼
         FastAPI: auth · API · бот · уведомления · фоновые задачи (раз в час)
                               │
       RouteService → RouteGenerator → Rule Engine (чистая логика, без БД и MAX)
                               │
         SQLAlchemy async → PostgreSQL ◄── seed из data/*.json
```

| Каталог | Что внутри |
|---|---|
| `backend/app` | API (`api/`), бот (`bot/`), движок правил (`rules/`), сценарии (`scenarios/`), маршруты, уведомления, клиент MAX |
| `backend/migrations`, `backend/tests` | Alembic, pytest |
| `frontend/src` | React-приложение, обёртка MAX Bridge (`shared/max`) |
| `data/` | Сценарии, региональные источники, вузы, регионы, раздел «Помощь» |
| `tools/` | Проверка API по DATA-API, проверка ссылок, сборка релиза |

Стек: Python 3.13, FastAPI, SQLAlchemy 2, Alembic, React 19, TypeScript, Vite, PostgreSQL 16+. Подробнее — [`docs/architecture.md`](docs/architecture.md).

## Запуск

```bash
cp .env.example .env
docker compose up --build        # http://localhost:8000
```

| | |
|---|---|
| **Порт** | `8000`: API, мини-приложение и `/docs`. Postgres наружу не открыт |
| **Остановка** | `docker compose down`. Сброс данных: `docker compose down -v` |
| **Повторный запуск** | `docker compose up -d` |
| **Что происходит при старте** | Применяются миграции, загружаются данные, запускается API |
| **Сборка** | 1–2 минуты |
| **Зависимости** | `backend/requirements.txt`, `frontend/package-lock.json` |

Вне MAX вход выполняется за тестового пользователя: `DEV_AUTH_ENABLED=true`, в production вход отключён. Если вписать в `.env` токен бота, бот заработает локально через long polling.

## Переменные окружения

Полный список с комментариями — [`.env.example`](.env.example). Секреты задаются только в окружении и в репозитории не хранятся.

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | PostgreSQL |
| `APP_ENV` | `development` / `production` |
| `PUBLIC_URL` | Публичный HTTPS-адрес (webhook, ссылки) |
| `MAX_BOT_TOKEN`, `MAX_BOT_USERNAME` | Токен и имя бота |
| `BOT_MODE` | `off` / `polling` / `webhook` |
| `MAX_BUTTON_MODE` | `link` (подписанная ссылка) или `open_app` (Mini App бота) |
| `SECRET_KEY`, `WEBHOOK_SECRET` | Подпись токенов, секрет webhook |
| `TEST_ACCESS_TOKENS` | Токены проверяющих: `token:max_user_id,…` |
| `SUPPORT_MAX_USER_IDS` | MAX ID команды: панель команды, сводки, оповещения, `/stats` (свой ID бот присылает на `/id`) |
| `REMINDERS_ENABLED`, `REMINDER_INTERVAL_SECONDS` | Фоновые напоминания |
| `DEV_AUTH_ENABLED`, `DEV_MAX_USER_ID` | Локальный вход без MAX |
| `RAG_URL`, `RAG_TOKEN`, `RAG_TIMEOUT_SECONDS` | RAG-сервис для вопросов ([`docs/rag.md`](docs/rag.md)). Пусто — отвечает встроенный поиск |
| `FRONTEND_URL`, `MAX_API_URL`, `SCENARIO_DATA_DIR` | Адрес приложения для CORS, адрес MAX API, каталог сценариев (значения по умолчанию подходят) |
| `ACCESS_TOKEN_TTL_SECONDS`, `LINK_TOKEN_TTL_SECONDS`, `INIT_DATA_MAX_AGE_SECONDS` | Сроки жизни токенов: 7 дней, 7 дней, сутки |
| `MAX_CA_BUNDLE`, `LOG_LEVEL`, `APP_VERSION` | Свой сертификат MAX, уровень логов, версия в `/health` |

## Внешние сервисы и интеграции

| Сервис | Зачем | Внутри Docker |
|---|---|---|
| **MAX Bot API и платформа MAX** | Бот, кнопки, webhook, запуск Mini App, проверка `initData` | **Нет.** Нужен токен бота от организаторов и клиент MAX. Без токена бот выключен, а приложение и API работают через dev-вход |
| **Render и Neon** | Прод: HTTPS-хостинг и PostgreSQL | Не нужны: локально работает Postgres из `compose.yaml` |
| **RAG-сервис команды** (необязательно) | Ответы на вопросы по шагам, `POST RAG_URL` | **Нет.** Отдельный сервис; без него отвечает встроенный поиск, для локальной проверки есть `tools/fake_rag.py` |
| **cron-job.org** | Пинг `/health` раз в 10 минут, чтобы бесплатный сервис не засыпал | Не нужен |
| **Яндекс Карты, Госуслуги, сайты МФЦ, ТФОМС и транспортных операторов** | Только ссылки из шагов: данные с них не загружаются, интеграции не имитируются | Не нужны |

Сертификат `platform-api2.max.ru` выпущен НУЦ Минцифры и лежит в `backend/certs/`. Деплой описан в [`docs/deploy.md`](docs/deploy.md).

## Данные

| Файл | Что в нём |
|---|---|
| `data/scenarios/*.json` | Сценарии: шаги, правила, документы, источники, английские тексты |
| `data/regional_services.json` | МФЦ (74 региона), фонд ОМС (60), студенческий проезд (36) |
| `data/universities.json`, `data/regions.json` | 214 вузов и колледжей, 89 регионов с часовыми поясами |
| `data/help.json` | Раздел «Если что-то пошло не так» |

- **Происхождение.** У каждого источника есть метка: `OFFICIAL` — официальная страница с датой проверки, `MOCK` — «Демонстрационные данные». Срок шага — рекомендация сервиса, а не требование закона. Тексты шагов — памятки команды.
- **Персональные данные.** Хранятся только `max_user_id`, ответы анкеты и язык. ФИО, паспортные и медицинские данные не собираются. Координаты для «Найти рядом» не уходят на сервер.
- **Обновление данных.** Как обновлять данные и проверять ссылки — [`docs/maintenance.md`](docs/maintenance.md).

## Тестовые данные и проверка

**Тестовые данные:**

- Проверяющие входят по токену из `TEST_ACCESS_TOKENS`. Сами токены передаются отдельно, их действия не попадают в метрики.
- Демонстрационные шаги в интерфейсе помечены «Демонстрационные данные».

**Проверка API:**

```bash
python3 tools/run_data_api.py --base-url https://marshrut-tf5o.onrender.com --token <тестовый токен>
# ожидается: 19 passed, 0 failed
```

**Проверка вручную в MAX.** Подробно — [`docs/demo.md`](docs/demo.md).

1. `/start` → «Открыть маршрут».
2. Ответы: гражданин РФ → Москва → другой вуз → 18 → очная → общежитие → регистрации нет → поликлиники нет.
3. Ожидается маршрут из 6 шагов: регистрация в общежитии, полис ОМС, поликлиника, проезд в Москве, Пушкинская карта, поддержка в вузе. В чат приходит «Ваш маршрут готов».
4. В шаге видны причина, документы, место, срок, источник Госуслуг с датой проверки.
5. «Отметить выполненным» → открывается следующий шаг, прогресс `1 из 6`, в чате «Следующий шаг».
6. Под сообщением бота «✅ Выполнено» → сообщение меняется на подтверждение, прогресс в приложении растёт.
7. После всех шагов — «Маршрут завершён 6 / 6» и поздравление в чате.

**Автотесты** (143: правила, данные, маршруты, API, авторизация, бот и фоновые задачи):

```bash
cd backend && DATABASE_URL=postgresql+asyncpg://postgres:postgres@localhost:5432/marshrut_test .venv/bin/pytest
```

## Ограничения

- **Региональные данные неполные.** Где официальных данных нет, шаг опирается на федеральный источник, а шаг о проезде помечен как демо. Цены проезда указаны на сентябрь 2026 и могут меняться.
- **Нет интеграции с госсистемами.** Сервис ведёт к официальной услуге, но не подаёт заявления.
- **Бесплатный тариф Render.** Сервис засыпает без трафика, поэтому его будит внешний пинг `/health`.
- **Вопросы текстом.** Пока RAG не подключён, ответ — это подходящий шаг маршрута с его источниками, а не свободный текст.
- **Английский — частично.** На английском сценарий иностранного студента, «Помощь» и бот. Сценарий для граждан РФ, названия регионов и вузов — только на русском.

## Масштабирование

Движок, модель данных и интерфейс одинаковы для любого контекста, меняются только данные:

- **Новый регион** — одна запись в `regional_services.json`.
- **Новый вуз** — запись в `universities.json`. Для партнёра ещё шаги с `university_code` и ссылка `?start=<код>`.
- **Новая категория пользователей** — новый файл сценария с правилом `audience`. Так без правок движка добавлен сценарий иностранного студента.
- **Пилот** — первокурсники одного-двух вузов Москвы. Метрики в `/api/v1/stats`: доля завершивших, время до регистрации, шаги после напоминаний, отзывы о данных.
