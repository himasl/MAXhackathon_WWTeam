# Маршрут

Чат-бот MAX с мини-приложением для студентов, которые переехали на учёбу в другой регион. По нескольким ответам он строит персональный маршрут дел: регистрация, полис и поликлиника, студенческий проезд, меры поддержки. У каждого шага — почему он появился, что сделать, какие документы взять, куда идти, рекомендуемый срок и официальный источник.

Трек «Забота о людях», направление «Интеграция новых жителей».

> «Маршрут» — не государственный сервис: он не принимает юридически значимых решений и не гарантирует право на льготу. Шаги отбирает детерминированный движок правил, а не LLM.

## Проблема и решение

Первокурсник собирает информацию с сайта вуза, Госуслуг, региональных порталов и из чатов и сам решает, что относится к нему и в каком порядке это делать. В итоге откладываются регистрация и прикрепление к поликлинике, а льготы теряются.

«Маршрут» собирает эти дела в один персональный план:

- **Анкета из 7–8 вопросов** (гражданство, регион, вуз, возраст, форма обучения, жильё, регистрация, поликлиника) → движок правил отбирает подходящие шаги.
- **Официальные региональные данные**: МФЦ, фонд ОМС и студенческий проезд своего региона — хотя бы один источник есть для всех 89 субъектов.
- **Бот ведёт по шагам**: присылает следующий, напоминает о сроке, закрывает шаг прямо из чата («✅ Выполнено», «⏰ Напомнить завтра», «🚶 Уже в процессе»). Ночью (22:00–9:00 по времени региона) не пишет, по воскресеньям присылает итоги недели.
- **Удобства в приложении**:
  - «План по дням»;
  - «🎒 Что взять с собой» — документы по местам, можно прислать список в чат;
  - «Найти рядом» — МФЦ или поликлиника на Яндекс Картах;
  - срок в календарь (.ics);
  - «Мне это не нужно» — пропустить шаг;
  - работа без интернета — сохранённая копия маршрута.
- **Забота и близкие**:
  - раздел «Помощь → Если что-то пошло не так» (паспорт, полис, болезнь, мошенники, телефоны 112/103/102);
  - ссылка для родителей только с прогрессом;
  - приглашение одногруппника;
  - карточка «Освоился за N дней».
- **Иностранные студенты**: отдельный сценарий (миграционный учёт, дактилоскопия, страховка), интерфейс и сообщения бота на английском. Язык выбирается по телефону, его можно переключить.

Отличие от жизненных ситуаций на Госуслугах: план персональный, региональные и вузовские шаги собраны вместе, прогресс и напоминания живут в мессенджере.

## Основной сценарий

```text
/start → «Открыть маршрут» → анкета → маршрут
→ шаг: причина, документы, место, срок, источник → «Отметить выполненным» → следующий шаг
→ … → «Маршрут завершён»
Бот параллельно: «маршрут готов», следующий шаг, напоминания, итоги недели, поздравление.
```

## Архитектура

Модульный монолит: один процесс FastAPI отдаёт API и собранное мини-приложение, а также принимает события бота.

```text
MAX (бот) ──webhook / polling──┐
MAX (Mini App, React) ──HTTPS──┤
                               ▼
                    FastAPI (app.main)
     auth · routes API · bot handler · notifications · фоновые задачи
                               │
          RouteService ──► RouteGenerator ──► Rule Engine (чистая логика)
                               │
             SQLAlchemy (async) ──► PostgreSQL ◄── seed из data/*.json
                                   MAXClient ◄── MessageSender (протокол)
```

- Доменная логика (`rules`, `scenarios/engine.py`) не зависит от FastAPI, БД и MAX.
- Сценарии, правила, источники и региональные данные хранятся как данные (`data/`), а не код.
- Фоновый цикл раз в час отправляет напоминания и недельные итоги, а также дайджест команде.

Подробнее — [`docs/architecture.md`](docs/architecture.md).

**Стек:**

- Python 3.13, FastAPI, Pydantic v2, SQLAlchemy 2 (async), Alembic, asyncpg, httpx.
- React 19, TypeScript, Vite, MAX Bridge.
- PostgreSQL 16+.
- Docker. Деплой: Render + Neon.

**Зависимости** зафиксированы в `backend/requirements.txt` и `frontend/package-lock.json`.

## Запуск

**Docker** (одна команда, порт `8000` — API, мини-приложение и `/docs`):

```bash
cp .env.example .env         # при желании вписать MAX_BOT_TOKEN — бот заработает через long polling
docker compose up --build    # остановить: docker compose down; сбросить данные: down -v; снова: up -d
```

При старте контейнер применяет миграции, загружает данные и запускает API. Сборка занимает 1–2 минуты.

**Без Docker** (Python 3.13, Node 22, PostgreSQL):

```bash
cd backend && python3.13 -m venv .venv && .venv/bin/pip install -r requirements.txt -e '.[dev]'
export DATABASE_URL=postgresql+asyncpg://postgres:postgres@localhost:5432/marshrut
.venv/bin/alembic upgrade head && .venv/bin/python -m app.scenarios.seed
DEV_AUTH_ENABLED=true .venv/bin/uvicorn app.main:app --reload
cd ../frontend && npm ci && VITE_API_URL=http://localhost:8000 npm run dev   # :5173
```

Вне MAX вход выполняется за тестового пользователя `DEV_MAX_USER_ID`. Это работает только при `DEV_AUTH_ENABLED=true` и не в production.

## Переменные окружения

Полный список с комментариями — в [`.env.example`](.env.example). Секреты задаются только через окружение, в Git их нет.

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | PostgreSQL (подходит и строка Neon `postgres://…?sslmode=require`) |
| `APP_ENV` | `development` / `production` (в production dev-вход выключен) |
| `PUBLIC_URL` | Публичный HTTPS-адрес для webhook и ссылок |
| `MAX_BOT_TOKEN`, `MAX_BOT_USERNAME` | Токен и имя бота |
| `BOT_MODE` | `off`, `polling` (локально) или `webhook` (production) |
| `MAX_BUTTON_MODE` | `link` (ссылка с подписанным входом) или `open_app` (Mini App бота) |
| `WEBHOOK_SECRET`, `SECRET_KEY` | Секрет webhook и ключ подписи токенов |
| `TEST_ACCESS_TOKENS` | Токены проверяющих: `token:max_user_id,…` |
| `SUPPORT_MAX_USER_IDS` | MAX ID команды: дайджест отзывов, алерты об ошибках, `/stats` в боте (свой ID бот присылает на `/id`) |
| `REMINDERS_ENABLED`, `REMINDER_INTERVAL_SECONDS` | Фоновые напоминания и итоги |
| `DEV_AUTH_ENABLED`, `DEV_MAX_USER_ID` | Локальный вход без MAX |

## Интеграция с MAX

- **Авторизация.** Мини-приложение передаёт `initData` в `POST /api/v1/auth/max`. Сервер проверяет подпись HMAC токеном бота и выдаёт токен доступа; `user_id` от клиента не принимается.
- **Кнопки.** В режиме `link` кнопки ведут на `PUBLIC_URL` с подписанным входом, в режиме `open_app` открывают Mini App бота. `start=step_<id>` открывает конкретный шаг.
- **События.** В production — webhook `POST /max/webhook` с проверкой секрета, подписка создаётся при старте. Локально — long polling.
- **Сертификат.** `platform-api2.max.ru` использует сертификат НУЦ Минцифры, он лежит в `backend/certs/`.

## API

Все методы, кроме `/health`, находятся под `/api/v1`. Авторизация — `Authorization: Bearer <token>`. Полное описание — в [`openapi.yaml`](openapi.yaml).

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/health` | Состояние: бот, база, `version` (commit сборки) |
| POST | `/auth/max` | initData → токен |
| GET | `/me` · PUT `/me/language` | Пользователь · язык интерфейса и бота |
| GET / PUT | `/profile` | Ответы анкеты |
| POST · GET | `/routes` · `/routes/current` | Построить маршрут · текущий маршрут |
| GET | `/routes/{id}/steps/{step_id}` | Карточка шага |
| POST | `…/complete` · `…/reopen` · `…/skip` | Выполнить · вернуть · «мне это не нужно» |
| POST | `…/calendar-link` · `…/report` | Ссылка на .ics · «Сообщить о неточности» |
| POST | `/routes/{id}/remind` | Прислать следующий шаг в чат |
| GET · POST | `/routes/{id}/checklist` · `…/send` | «Что взять с собой» · в чат |
| POST / DELETE | `/routes/share` | Ссылка для родителей · отключить ссылки |
| GET | `/shared/{token}` · `/calendar/{token}.ics` | Прогресс по ссылке · файл календаря |
| GET | `/regions` · `/universities` · `/help` · `/config` · `/stats` | Справочники, «Помощь», метрики пилота |

**Ошибки** приходят в едином формате: `{"error": {"code": "…", "message": "…"}}`, коды 401/404/409/422/503. При ошибке 500 в ответе и заголовке `X-Request-ID` есть код, по которому её легко найти в логах.

**Проверка контракта** против живого сервера:

```bash
python3 tools/run_data_api.py --base-url https://marshrut-tf5o.onrender.com --token <тестовый токен>
```

## Данные

| Файл | Что в нём |
|---|---|
| `data/scenarios/*.json` | Сценарии: шаги, правила, документы, источники, переводы (`i18n`) |
| `data/regional_services.json` | МФЦ (74 региона), фонд ОМС (60), студенческий проезд (36) |
| `data/regional_candidates.json` | Непроверенные ссылки — в сервис не загружаются |
| `data/universities.json` · `data/regions.json` | 214 вузов и колледжей · 89 регионов с часовыми поясами |
| `data/help.json` | Раздел «Если что-то пошло не так» |

- **Загрузка.** Данные загружаются при старте (`python -m app.scenarios.seed`). Региональный файл применяется к сценарию без правок движка: новый регион — это одна запись.
- **Версии сценариев.** Опубликованная версия сценария в БД не переписывается, поэтому правка данных требует новой `version`. Это проверяет тест `test_scenario_versions`.
- **Происхождение данных.** Каждый источник помечен: `OFFICIAL` — официальная страница с датой проверки; `MOCK` — «Демонстрационные данные»; рекомендуемый срок рассчитан сервисом. Тексты шагов — памятки команды, интеграции с госсистемами не имитируются.
- **Персональные данные.** Хранятся только `max_user_id`, ответы анкеты и выбранный язык. ФИО, паспортные и медицинские данные не собираются, координаты для «Найти рядом» на сервер не уходят.
- **Тестовые данные.** Проверяющие входят по `TEST_ACCESS_TOKENS`, их действия не попадают в метрики. Локально вход идёт за `DEV_MAX_USER_ID`.

## Проверка вручную

Подробно — в [`docs/demo.md`](docs/demo.md).

1. В MAX открыть бота → `/start` → «Открыть маршрут».
2. Ответить: гражданин РФ → Москва → другой вуз → 18 → очная → общежитие → регистрации нет → поликлиники нет.
3. Ожидается 6 шагов: регистрация в общежитии, полис ОМС, поликлиника, студенческий проезд в Москве, Пушкинская карта, поддержка в вузе.
4. Открыть шаг: видны причина, документы, место, срок и официальный источник с датой проверки.
5. «Отметить выполненным» → открывается следующий шаг, прогресс растёт, бот присылает следующий шаг.
6. Выполнить все шаги → экран «Маршрут завершён 6 / 6» и поздравление в чате.

## Ограничения

- **Региональные данные неполные.** Официальные данные есть не по всем темам: где их нет, шаг опирается на федеральный источник, а шаг о проезде помечен как демо. Цены проезда пересказаны на дату проверки (сентябрь 2026) и могут меняться.
- **Интеграций с госсистемами нет.** Сервис ведёт к официальной услуге, но не подаёт заявления.
- **Сервис засыпает без трафика.** Это Render Free; бодрствование поддерживает внешний пинг `/health`.
- **Английский перевод частичный.** На английском — сценарий иностранного студента, «Помощь» и сообщения бота. Сценарий для граждан РФ, названия регионов и вузов — только на русском.

## Масштабирование

Ядро одинаково для всех контекстов: анкета → правила → сценарий → маршрут → уведомления. Меняются только данные:

- **Новый регион** — одна запись в `regional_services.json`.
- **Новый вуз** — запись в `universities.json`. Для партнёра — шаги с `university_code` и ссылка `?start=<код>`.
- **Новая категория пользователей** — новый файл сценария с правилом `audience`. Так без правок движка добавлен сценарий иностранного студента.
- **Пилот** — первокурсники одного-двух вузов Казани, ссылка в чатах групп и при заселении. Метрики в `/stats`: доля завершивших маршрут, время до регистрации, шаги, закрытые после напоминаний, отзывы о данных.
