# Демо-сценарий

## В MAX (основной)

1. Открыть бота [@t818_hakaton_max_bot](https://max.ru/t818_hakaton_max_bot) в мобильном или веб-клиенте MAX и отправить `/start`.
   Ожидается: приветствие с кнопкой «Открыть маршрут».
2. Нажать «Открыть маршрут». Открывается мини-приложение, экран «Добро пожаловать».
3. «Составить маршрут» → ответы: **Москва → 18 → Очная → В общежитии → Нет → Нет** → «Составить маршрут».
4. Ожидается экран «Ваш маршрут», `0 из 6 выполнено`:
   1. Регистрация по месту пребывания в общежитии — следующий шаг, «желательно до …»
   2. Проверка полиса ОМС
   3. Прикрепление к поликлинике
   4. Студенческий проезд в Москве
   5. Пушкинская карта
   6. Меры поддержки в вузе (по желанию)

   В чате бота приходит «Ваш маршрут готов» с кнопкой «Открыть шаг».
5. Открыть первый шаг. Видны блоки «Почему этот шаг появился?», «Что сделать», «Документы», «Куда обратиться», «Рекомендуемый срок» и «Источник» (метка «Официальный источник», Госуслуги, дата проверки, кнопка открытия).
6. «Отметить выполненным» → открывается следующий шаг, прогресс `1 из 6`, в чат приходит «Следующий шаг».
7. На экране маршрута нажать «Напомнить о следующем шаге в MAX» → в чате появляется напоминание.
8. В чате отправить `/next` → бот присылает текущий следующий шаг.
9. Выполнить оставшиеся шаги → экран «🎉 Маршрут завершён 6 / 6», в чате поздравление.
10. «Изменить ответы и пересобрать маршрут» → например, «Санкт-Петербург», «Снимаю квартиру»: маршрут перестраивается (регистрация через Госуслуги/МФЦ, проездной СПб).

Другие профили для проверки правил:

| Профиль | Ожидаемые шаги |
|---|---|
| Татарстан, 25, очная, общежитие, регистрация есть, поликлиники нет | ОМС, поликлиника, проезд в Казани, поддержка в вузе |
| Другой регион, 18, заочная, общежитие, регистрация есть | ОМС, поликлиника, Пушкинская карта, поддержка в вузе |

Шаг «проезд в другом регионе» и «поддержка в вузе» помечены как «Демонстрационные данные».

## Проверка API

```bash
python tools/run_data_api.py --base-url https://marshrut-tf5o.onrender.com --token <тестовый токен>
```

Ожидается `13 passed, 0 failed`.

## Локально без MAX

```bash
cp .env.example .env
docker compose up --build
```

Открыть http://localhost:8000 — вход выполняется за development-пользователя, сценарий тот же, что и выше, начиная с шага 2.
